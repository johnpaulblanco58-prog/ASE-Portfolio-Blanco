# ASE-Portfolio-Blanco
Completion of CPELX230-330 Week02-04 Activity


This repository serves as my personal portfolio for the course Agentic Software Engineering (ASE). It contains the learning materials, activities, concept analyses, and reflections developed throughout the course, particularly focusing on Agentic Software Engineering, intelligent AI agents, Agile software development, version control, and responsible AI practices.

It aims to document my understanding of how AI-powered agents are integrated into modern software development, how they differ from traditional software systems, and how they can be utilized to address real-world problems. It also highlights the importance of ethical AI development, data privacy, security, and human oversight in ensuring that autonomous systems are reliable, safe, and beneficial to society.

These are the following files in this repository:
* Course Introduction
* Personal Learning Objetives
* Concept Analysis
* Reflection
